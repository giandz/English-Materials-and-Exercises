One thing: There is (There's) + a / an: There's a sofa.

Two or more: There are + two, three, four…: There are four chairs.

Negative: There isn't a bathtub. · There aren't any chairs.

Question: Is there a TV? — Yes, there is. / No, there isn't.
Are there any plants? — Yes, there are. / No, there aren't.

How many? How many chairs are there? — There are four.

Short answers have no contraction: Yes, there is. (not Yes, there's.)
