There is / There are

Talking about what exists — count and noncount nouns

We use there is / there are to say what exists or what we can see in a place.

Count nouns (things we can number: 1 apple, 2 apples) use is for one thing and are for more than one.

Noncount nouns (things we don't number: meat, water, rice) always use is, usually with some or any.

there is / are noun negation
Affirmative — Count Nouns
singular
🍎

There is an apple.

plural
🍎×2

There are two apples.

plural
🐟×3

There are three fish.

Affirmative — Noncount Nouns
noncount
🥩☑️

There is some meat.

noncount
💧☑️

There is some water.

noncount
🍚☑️

There is some rice.

In affirmative sentences, noncount and plural nouns usually take some.

Negative — "not" form
singular
🍎❌

There isn't an apple.

plural
🐟🐟❌

There aren't any fish.

noncount
🥦❌

There isn't any broccoli.

Negative — "no" form
singular
🍎❌

There's no apple.

plural
🐟🐟❌

There are no fish.

noncount
🥦❌

There's no broccoli.

Two ways to say the same negative sentence — both are correct and mean the same thing:

with "not" + anywith "no"
There isn't an apple.There's no apple.
There aren't any apples.There are no apples.
There isn't any meat.There's no meat.

"No" replaces "any" and goes directly before the noun. It never uses isn't/aren't — the verb stays positive: There's no, There are no.
