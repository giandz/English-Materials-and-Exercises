There Is / There Are A1 / A2

We use there is / there are to say what exists in a place. The word we use for "how much/many" depends on whether the noun is count (has a plural) or noncount (no plural).

How much? How many?
Count nouns — there ARE
a park → parks · a restaurant → restaurants · a museum → museums
no / not any
a few / several
many / a lot of
zero → small number → large number
Noncount nouns — there IS
traffic · crime · noise · pollution (no plural form)
no / not any
a little
much / a lot of
zero → small amount → large amount
💡 Some and a lot of work for BOTH count and noncount nouns: there's some traffic / there are some parks · a lot of noise / a lot of restaurants.

💡 much is mostly used in negatives and questions (there isn't much traffic / is there much traffic?); in affirmative sentences, native speakers usually prefer a lot of (there's a lot of traffic) instead of there's much traffic.
Affirmative, negative & question forms
There is/are + a/some/a few/a little/many/much/a lot of + noun
  • There's a lot of traffic.
  • There are a few parks nearby.
  • There's a supermarket on this street.
There isn't/aren't + any/much/many + noun
  • There isn't much crime here.
  • There aren't many restaurants around here.
  • There aren't any museums in this town.
Is/Are there + any/much/many + noun?
  • Is there much pollution in your city?
  • Are there many schools nearby?
  • Is there a bus stop near here?
there is/are determiner noun negation is/are (question)
Remember: the noun after there is/are decides the verb — singular/noncount noun → is, plural noun → are. This also decides the determiner: much/a little only go with noncount nouns; many/a few only go with count nouns.
