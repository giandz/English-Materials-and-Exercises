🎬 Recording with OBS

1. Set the delay (1.5 s suits most sentences). 2. Open this page in Chrome or Edge and press H for the recording view. 3. In OBS add a Window Capture of this window, then a Chroma Key filter on it (or use a Transparent background in a Browser source). 4. In OBS’s Advanced Audio Properties give your microphone a Sync Offset equal to the delay. Browser sources in OBS usually can’t open the microphone, so Window Capture is the safer route.
